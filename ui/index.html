Adicionar projeto

Pasta a adicionar
Clique para selecionar, clique duplo (ou Enter) para entrar na pasta. Sem seleção, adiciona a pasta aberta. Repositórios git aparecem com a branch.
Procura pastas com .git sem rodar o git; ignora node_modules, venv, dist, build e pastas ocultas.

Adicionar agente

Minúsculas, números, - ou _. É o nome que o agente usa em a2a inbox --agent NOME.
Cole isto como primeira mensagem na sessão do agente (ou adicione o AGENTS.md ao projeto com a2a onboard --agents-md).
